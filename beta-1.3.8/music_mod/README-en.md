# Music Sobos

Play one song from your computer and shake every sobo with it.

Choose an mp3, ogg or wav file in the game settings. Play is off until you turn it on. A heavier number moves less, because the game's own mass already grows with the number. Shake range starts at 100%, the same shake as 1.0.0, and can be set from 0% to 300%. The song is not included in this mod.
